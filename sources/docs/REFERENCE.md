## 카탈란 수, 심슨 적분, 그런디 정리, 픽의 정리, 페르마 포인트, 오일러 정리

카탈란 수: C(n) = comb(2*n,n) // (n+1). 처음 값은 1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862, 16796, 58786, 208012, 742900. 길이 2n의 올바른 괄호 문자열, 잎 n+1개의 순서 있는 full binary tree, 볼록 (n+2)각형의 삼각 분할을 센다.

심슨 공식: n은 양의 짝수, h=(b-a)/n, x_i=a+i*h. 적분 근삿값은 h/3 * (f(x_0)+f(x_n)+4*sum(f(x_i), i 홀수)+2*sum(f(x_i), 0<i<n 짝수)). f의 4계 도함수가 연속이고 절댓값이 M 이하이면 절대 오차는 M*(b-a)*h^4/180 이하.

Nim: 일반 규칙에서는 모든 더미 크기의 XOR가 0이면 후공 승리, 아니면 선공 승리. Grundy 값은 가능한 다음 상태의 값들의 mex(포함되지 않은 최소 비음수 정수). 독립적인 게임의 합은 각 Grundy 값의 XOR. 유한 비순환 impartial normal-play 게임에 적용한다.

Subtraction game: 한 번에 한 더미에서 1..k개를 제거할 때 각 더미 크기를 k+1로 나눈 나머지가 Grundy 값이다. 이 값들의 XOR로 판단한다.

Index-k Nim (Moore's Nim): 한 번에 1..k개 더미를 고르고 각 더미에서 양의 개수를 제거한다. 각 이진 자릿수에서 1의 개수를 k+1로 나눈 나머지가 모두 0인 상태가 패배 상태다. 이 나머지 벡터를 일반적인 Grundy 값으로 취급하지 않는다.

Misere Nim: 마지막 돌을 가져가는 쪽이 패배한다. 0인 더미를 제외하고 모두 크기 1이면 양의 더미 수가 홀수일 때 후공 승리. 크기 2 이상 더미가 있으면 XOR가 0일 때 후공 승리. 빈 시작 상태는 게임 규칙의 종료 정의를 확인한다.

Pick 정리: 단순 격자 다각형에서 넓이 A = 내부 격자점 수 I + 경계 격자점 수 B/2 - 1. 경계 격자점 수는 각 변의 gcd(abs(dx), abs(dy)) 합이다. floor_sum(n,m,a,b)는 i=0..n-1에 대해 floor((a*i+b)/m)를 합한다. 아래 Reference.py에 반복형 구현을 포함했다.

페르마 포인트: 삼각형 꼭짓점까지 거리 합을 최소화한다. 120도 이상인 각이 있으면 그 꼭짓점이다. 모든 각이 120도 미만이면 각 변 바깥쪽 정삼각형의 새 꼭짓점과 반대 꼭짓점을 잇는 선분들이 만나는 점이다. 최소 거리 합은 sqrt((a*a+b*b+c*c+4*sqrt(3)*A)/2), A는 삼각형 넓이.

오일러 정리: gcd(a,m)=1이면 a^phi(m) = 1 (mod m). 이 경우 지수를 phi(m)로 나눠 줄일 수 있다. 서로소가 아닐 때 무조건 지수를 줄이면 틀린다. 충분한 지수 e >= ceil(log2(m)), m>=2에서는 a^e = a^(e % phi(m) + phi(m)) (mod m)를 사용할 수 있다. 작은 지수는 원래대로 계산한다.

소수 p에 대해 g^0+...+g^(p-2)는 g=1 (mod p)이면 -1 (mod p), g가 0도 1도 아니면 0 (mod p)이다. g=0이면 합은 1이므로 별도 처리한다.

## 경우의 수 - 포함 배제, 스털링 수, 벨 수

구별되는 n개 공을 구별되는 k개 상자에 모두 비지 않게 넣는 경우(전사 함수): sum((-1)^(k-i)*comb(k,i)*i^n, i=0..k) = k!*S2(n,k). 원문 첫 항목의 '공 구별 X'를 '공 구별 O'로 정정했다. 구별되지 않는 공, 구별되는 양의 상자라면 comb(n-1,k-1)이다.

구별되는 공, 구별되지 않는 k개 비지 않은 상자: 제2종 스털링 수 S2(n,k)=k*S2(n-1,k)+S2(n-1,k-1). S2(0,0)=1, 유효 범위 밖은 0. 포함 배제식은 위 전사 함수 수를 k!로 나눈 값이다. 모듈러 나눗셈에는 역원의 존재 조건을 확인한다.

벨 수: B(n)=sum(S2(n,k), k=0..n). 최대 k개 블록이면 B(n,k)=sum(S2(n,j), j=0..k). B(n)=sum(comb(n-1,i)*B(i), i=0..n-1), B(0)=1. 최대 k개 식은 sum(i^n/i! * sum((-1)^j/j!, j=0..k-i), i=0..k)로도 정리된다. 이 식의 나눗셈은 유리수 또는 유효한 모듈러 역원으로 계산한다.

완전 순열: D(0)=1, D(1)=0, D(n)=(n-1)*(D(n-1)+D(n-2)).

부호 없는 제1종 스털링 수: c(n,k)=(n-1)*c(n-1,k)+c(n-1,k-1). 부호 있는 제1종 스털링 수: s(n,k)=s(n-1,k-1)-(n-1)*s(n-1,k). 둘 다 (0,0)=1. 원문의 signed 점화식 부호를 정정했다.

정수 n을 정확히 k개의 양의 정수로 분할: p(n,k)=p(n-1,k-1)+p(n-k,k), p(0,0)=1. 전체 분할 수: p(0)=1, p(n)=sum((-1)^(k-1)*(p(n-k*(3*k-1)//2)+p(n-k*(3*k+1)//2)), k>=1; 음수 인자의 p는 0. 원문의 부호를 정정했다.

카탈란 등가식: C(n)=comb(2*n,n)-comb(2*n,n+1)=(2*n)!/(n!*(n+1)!). C(0)=1, C(n)=sum(C(i)*C(n-1-i), i=0..n-1) for n>=1.

## 삼각형의 오심 - 외심, 내심, 무게중심, 수심, 방심

비퇴화 삼각형에서 변 a,b,c는 각각 꼭짓점 A,B,C의 맞은편 길이. 반둘레 p=(a+b+c)/2. 넓이 K=sqrt(p*(p-a)*(p-b)*(p-c)). 외접 반지름 R=a*b*c/(4*K), 내접 반지름 r=K/p.

중선 m_a=sqrt(2*b*b+2*c*c-a*a)/2. 각 이등분선 길이 t_a=sqrt(b*c*(1-(a/(b+c))^2)). 사인 법칙 sin(A)/a=1/(2*R). 코사인 법칙 a*a=b*b+c*c-2*b*c*cos(A). 탄젠트 법칙 (a+b)/(a-b)=tan((A+B)/2)/tan((A-B)/2), 분모가 0이면 별도 처리.

무게 (alpha,beta,gamma)에 대응하는 점은 (alpha*A+beta*B+gamma*C)/(alpha+beta+gamma). X=b*b+c*c-a*a, Y=a*a+c*c-b*b, Z=a*a+b*b-c*c라 두면 외심의 무게는 (a*a*X,b*b*Y,c*c*Z), 내심은 (a,b,c), 무게중심은 (1,1,1), 수심은 (Y*Z,Z*X,X*Y), A에 대응하는 방심은 (-a,b,c). 직각 삼각형의 수심 공식은 0/0이 될 수 있으므로 직각 꼭짓점을 직접 반환한다.

## 미적분, 뉴턴 랩슨법

실수 정의역에서 (arcsin x)'=1/sqrt(1-x*x), (arccos x)'=-1/sqrt(1-x*x), (arctan x)'=1/(1+x*x), (tan x)'=1+tan(x)^2.

적분 tan(a*x) dx = -ln(abs(cos(a*x)))/a + C. 적분 x*sin(a*x) dx = (sin(a*x)-a*x*cos(a*x))/(a*a)+C. 두 식 모두 a != 0.

Newton: x_next=x-f(x)/f'(x). 초기 추정치와 도함수에 따라 발산·순환할 수 있다. 잔차, 도함수 0, 반복 상한을 확인한다. 이분 탐색처럼 수렴이 보장되는 방법과 혼용할 수 있다.

Green 정리: 경계 C에서 integral(L dx + M dy) = 영역 D에서 double_integral(dM/dx - dL/dy) dx dy. C는 양의 방향의 조각별 매끄러운 단순 폐곡선, L,M은 D를 포함하는 열린 영역에서 연속 편도함수를 가져야 한다.

# 추가 자료 편집 기록

사용자가 제공한 자료는 `provided.txt`에 보존합니다. 추가판은 기존 8.5pt 혼합판 뒤에 이 자료의 새 내용을 붙입니다. 목차·제목 번호·색·2단 형식은 본문과 같습니다.

- 빠른 참조: 코드 앞의 주석 기호를 제거하고 설명용 인라인 주석만 유지합니다. 예시들은 각각 독립된 사용법이며 전체를 순서대로 실행하는 프로그램이 아닙니다. 필요한 값은 예제별로 준비합니다.
- 기존 정렬·이진 탐색·최대공약수·힙·큐 사용과 중복되는 빠른 참조 줄은 제외합니다.
- 최초 참 탐색은 기존 8.2를 재사용합니다. 기존 함수의 `[lo,hi)` 규약에 맞춰 곱셈표의 상한을 `n*n+1`로 지정합니다.
- 벡터 뺄셈·내적·외적·거리 제곱은 기존 7.1을 재사용합니다. 거리 제곱 함수 이름은 `distance_squared`로 맞춥니다.
- 편집 거리와 곱셈표 순위, 수선의 발·점과 직선 거리·대칭점·수평/수직선 교점을 추가합니다. 직선을 정의할 수 없는 입력과 실수 근사 조건을 표시합니다.
- 이미 수록된 경계·빈 입력·그래프·재귀·부동소수점 점검은 반복하지 않고, DP와 출력 등 새 점검만 남깁니다.

추가 알고리즘은 `sources/`에서 import할 수 있습니다. 제출 시 위에서 재사용한 함수도 함께 복사하고 저장소 전용 `from python...` import는 제거합니다.
